# Community intelligence upgrade — October 11, 2026

Both community members and leadership are prioritized. Community profiles now show an overview of current indexed jobs, upcoming/ongoing events, and news in the last 14 days. Employment previews link to original postings and detailed profile filters; communities without a verified current posting retain direct employer-source links where configured.

Event status is calculated from dates, including in the browser between collector runs. Seven daily calendar aggregates are held in the review queue rather than presented as individual events. Forty-five stale source status labels were corrected. The date-window retains ongoing multi-day events. Final event collection: 121 records. Event source pages and extraction dates still need individual verification where flagged; this release does not certify every event.

All 397 current job records are retained. Generic job-board/contact-heading cards remain in Pending verification; a future deadline cannot override Closed or Pending verification. Dated openings also require a recent source check. A source outage retains previous jobs with the original lastChecked date rather than falsely refreshing them. The Treaty Six Child and Family Services Lead posting is manually reviewed against the preserved two-page official PDF, including pay range and October 19 deadline. Dene Tha’s 2027 deadlines were checked against official pages and retained as stated; they are not silently corrected to a guessed year.

350 news articles remain. News, events, and employment document review history survives subsequent partial scans. Snapshot folders preserve pre-upgrade and newer automated records. The source PDF, changes report, and file hashes are versioned here for recovery.

Existing daily workflows now scan both Saskatchewan and Alberta by default, start from the latest branch, and share the data-writer concurrency group. Sources that block fetching or require an authorized Facebook API remain limitations; access controls are not bypassed. Tests cover source outages, status boundaries, calendar aggregates, review preservation, and document title selection.
