About OpenBand

OpenBand is an independent public-records tool by SevenGenStudios. It helps people find and review First Nations financial statements, remuneration schedules, and original public documents.

Our purpose

Make published records easier to locate, read, and verify. Nation profiles also organize community information and public updates where sourced. OpenBand is not a government service or a Nation’s official website.

What is covered?

The current directory covers Saskatchewan and Alberta. Financial data comes from published ISC FNFTA filings, with extraction and review status preserved. Coverage can be incomplete, and an absent extraction is not a claim that a Nation did not file a document.
